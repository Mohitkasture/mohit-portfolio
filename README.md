# Mohit Kasture — Portfolio

Personal site for a Django REST Framework backend developer. Single-page Django templates, custom CSS, minimal JS.

## Run locally

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open http://127.0.0.1:8000/

Update email, GitHub, and LinkedIn in `home/templates/home/index.html`.
